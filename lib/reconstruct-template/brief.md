# Rebuild the pictured video in editable Remotion layers

Read index.json for the exact canvas, frame rate, total frames, detected cuts and source frame at each contact-sheet cell. The cells run left to right, top to bottom. Pixel coordinates below refer to the original canvas. Inspect individual reference images when available. The audio master is supplied separately by MStudio.

Author the full content of project/src/layers.json. Match visible wording, graphics, palette, layout, timing, easing and camera-like motion as closely as the evidence allows. Draw distinguishable foreground items separately. Use SVG paths to describe complex contours and typography if appropriate. Keep useful object names for later editing. For footage, approximate the visible objects using independently editable vectors and list significant omissions. Video imagery, linked or encoded media, image sequences, and executable code are outside this document format. Use the exact keys below. Filenames, paths and additional fields are not accepted.

Replace the example completely. Scene ranges use absolute frame numbers, start inclusive and end exclusive. Cover frame zero through the full number of frames with contiguous scenes. Inside each scene use an ordered layers array, back to front, and a solid or gradient background. An empty layers array is valid for a genuine blank interval. At least one layer in the film must describe a visible object. IDs begin with an ASCII letter and contain letters, digits, hyphens or underscores. Labels may use any language.

Every layer needs id, label, type. Choose rect, ellipse, line, path or text. x/y place the local origin. Numeric scaleX/scaleY default to 1, rotation is degrees, originX/originY set the local pivot. Opacity ranges from 0 to 1. Optional from/to restrict visibility in **scene-local frames** and default to the entire scene. Paint with fill/stroke and strokeWidth. Colors are hex or none/transparent. Linear gradients are optional per scene: gradients:[{"id":"sky","x1":0,"y1":0,"x2":0,"y2":1,"stops":[{"offset":0,"color":"#edf3ff"},{"offset":1,"color":"#233145"}]}]. Reference them as "url(#sky)" in fill, stroke or background. Gradient coordinates and stop offsets are fractions. Stops may also specify opacity.

Rect uses width,height and optional rx (rounded corners) at its top-left origin. Ellipse uses rx,ry measured from its central origin. Line goes from local (0,0) to x2,y2 and needs a visible stroke. Path uses SVG d commands in local coordinates. Text uses text with optional newlines, fontFamily, numeric fontWeight, fontSize, letterSpacing, lineHeight and anchor ("start", "middle" or "end"). x,y position its first baseline.

Animate with an optional keyframes array sorted by frame (scene-local time). Each keyframe gives frame and one or more numeric properties: x, y, scaleX, scaleY, rotation, opacity, width, height, rx, ry, x2, y2, strokeWidth, fontSize, lineHeight or letterSpacing. Values interpolate linearly, independently for each property, from its base value at scene frame 0. After its last key the value holds. Approximate nonlinear motion with intermediate keys. Do not redraw the whole scene for each frame.

In limitations list unreadable text, unobserved transitions, approximate faces or scenery, unavailable fonts, and other specific uncertainties, as appropriate. Supply an empty list when no limitations were identified.

Any layer may have clip:{"x":120,"y":40,"width":500,"height":180}. This is a fixed rectangular viewport in composition coordinates: the layer can move beneath it. For a chart trace or handwritten reveal, a path can have pathLength:1, strokeDasharray:[1,1], strokeDashoffset:1, then animate strokeDashoffset to 0 with keyframes. Stroke dashes are also available on other shapes. A scrolling chart can animate its x position inside a fixed clip.
